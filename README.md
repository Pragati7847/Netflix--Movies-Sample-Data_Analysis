# Netflix--Movies-Sample-Data_Analysis
Project Overview

The Movies Analytics Dashboard is an interactive data visualization project developed using Microsoft Power BI. It analyzes movie data to uncover insights into movie categories, IMDb ratings, release years, age ratings, and movie duration.

The dashboard presents key performance indicators (KPIs) and interactive charts to help users explore movie trends, compare ratings, and identify highly rated movies. It demonstrates practical skills in data analysis, data visualization, and business intelligence.

🎯 Project Objectives

- Analyze the distribution of movies across different categories.
- Calculate the average IMDb rating of movies.
- Explore movie release trends over the years.
- Analyze the relationship between movie duration and IMDb ratings.
- Understand the distribution of movies by age rating.
- Identify the top 10 highest-rated movies.

📊 Dashboard Features

1. Key Performance Indicators (KPIs)

- Total Movies: Displays the number of distinct movies.
- Average IMDb Rating: Shows the average rating across movies.
- Release Years: Displays the number of distinct release years.
- Average Duration: Calculates the average movie duration.
- First and Latest Release Year: Shows the earliest and latest years in the dataset.

2. Interactive Visualizations

- Movies by Category: A bar chart showing the number of movies in each category.
- IMDb Rating by Year: A line chart displaying rating trends over time.
- Duration vs. IMDb Rating: A scatter chart exploring the relationship between movie duration and ratings.
- Age Rating Distribution: A donut chart showing the distribution of movies by age classification.
- Top 10 Movies: A table highlighting the highest-rated movies.

3. Interactive Filtering

The dashboard includes filters and slicers that allow users to explore the data by:

- Release Year
- Movie Category
- Age Rating

These filters help users explore different subsets of the dataset and compare results interactively.

🛠️ Tools and Technologies

- Microsoft Power BI Desktop — Dashboard development and visualization
- Power Query — Data cleaning and transformation
- DAX (Data Analysis Expressions) — KPI calculations and analytical measures
- Data Visualization — Charts, cards, and interactive filters

📁 Dataset

The project uses a movie dataset containing the following fields:

Column| Description
Name| Movie title
Category| Movie category or genre
Age Rating| Movie age classification
IMDb Rating| Movie rating
Duration| Movie duration
Year| Movie release year

🚀 How to Use

1. Download or clone this repository.
2. Install "Microsoft Power BI Desktop" (https://www.microsoft.com/power-platform/products/power-bi/desktop).
3. Open the ".pbix" dashboard file in Power BI Desktop.
4. If the dataset is stored separately, update the data source path as required.
5. Refresh the data if necessary.
6. Use the charts and slicers to explore the movie data.
